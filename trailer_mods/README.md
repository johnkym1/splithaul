# Trailer mod release metadata

The metadata folders contain the manifests, descriptions and approved Mod Manager
artwork for the packaged ATS and ETS2 mods. The .scs archives are distributed as
GitHub release assets and bundled in Setup. Their versions and SHA-256 hashes
are pinned in ../installer/trailer_mods.json.

These files do not contain the SCS trailer models or form a complete mod by
themselves. Preserve the established GT filenames and display names when updating.
