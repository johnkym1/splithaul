SPLITHAUL by grumpyman

This is a test installer for the Windows 64-bit development build.
Single-player ATS or ETS2, an attached owned combination, and a compatible game
build are required. ATS allows 1-3 trailers; ETS2 allows 1-2. Recognised SCS
converter dollies are excluded. Unknown components count as trailers. Single means one delivery; Dual means two; Multi-drop supports 3-8 deliveries.

INSTALLATION
Close SplitHaul and both games normally first.
Choose the app folder. ATS and ETS2 telemetry and trailer-mod installation are
checked by default. Uncheck the tasks for any game you do not use. For telemetry,
browse to each selected game's main Steam folder. Unsupported executable builds are
rejected before any game DLL is replaced. Existing GT_Telemetry.dll files are
backed up. Other plugins, game profiles and saves are not modified.
For trailer mods, select each game's data folder in Documents (containing
config.cfg), or its custom -homedir. Setup installs into the mod subfolder.
The same mod filenames and Mod Manager names are retained on every update.
After installing, enable GT Multi-Trailer Combinations in each chosen profile's
Mod Manager. Existing active entries can stay enabled. See TrailerMods.txt or
the Start menu's Trailer mod guide for combinations, versions and DLC needs.

SETTINGS AND HISTORY
Each Windows user keeps their own data in:
  %LOCALAPPDATA%\Grumpyman\SplitHaul
Game profiles are separated into profiles and profiles_ets2 subfolders.
An update refreshes packaged catalogs while preserving settings and histories.
Your existing development-folder history is not automatically imported.

FIRST RUN
Open SplitHaul from the Start menu once to register Shift+F9.
Then start ATS or ETS2. When just one game is running, the app selects that
game automatically. If it switches from the other game, it starts in single
mode; choose Dual or Multi-drop in Options for more deliveries. Attach your
owned combination and enter Drive. Dispatch while stopped.
Keep the companion open during a delivery plan.
Shift+F9 opens or focuses the companion. Do not use sdk reload for normal use.
Cancellation requires a stopped truck and the game pause menu.
After delivery, review the result and acknowledge completion.
History can be exported with Export CSV and the Save As dialog.

HOW TO USE IT IN GAME - SHIFT + F9
1. In the driver's seat, stop the truck. Hold SHIFT and tap F9 to open or
   bring SplitHaul to the front. F9 alone is not the shortcut.
2. If the app does not open, start it once from the Windows Start menu, then
   return to the game and try SHIFT + F9 again.
3. In Options, check the game and choose Single, Dual or Multi-drop. The sole running
   game is detected automatically. Dual means two delivery stops.
4. Choose pickup, cargo and delivery company in the app, then dispatch while
   stopped. Return to the game and follow the route to the green pickup flag.
5. For two stops, deliver the first load normally. Keep the app open; the
   remaining cargo is assigned to the second stop automatically. Finish the
   second delivery, review the result and acknowledge completion.
No SDK reload is needed between deliveries. Use History to view or export jobs.

MULTI-DROP
Choose pickup, cargo and final city/company first. Choose from the available delivery counts (3-8 maximum); the
final city counts as one, and the pickup does not count. With Automatic selected,
press Generate stops. With Manual, select each numbered delivery city and company.
You can edit automatic suggestions individually. Review the full itinerary in
Job details before dispatch. Automatic suggestions use city positions, not the
game road network. Every depot and remaining load is checked before assignment.
Cargo is split evenly in whole units, with any extra units at the first stops.
The game supplies capacity for the complete combination; it is not multiplied
by trailer count. All trailers stay attached throughout the trip. Deliver normally
and return to Drive stopped for the next loaded leg. Keep the app and game open;
a game restart does not automatically resume an unfinished multi-stop sequence.
Preferred km is saved separately for ATS and ETS2. Use 0 for a direct route, or
enter a distance up to 10000 km. Round trip locks the final city to the pickup
city; choose a different final company and a nonzero preferred distance.
The planner aims for the preferred distance, allowing 20% extra. City-distance
estimates do not follow roads or ferries, so the game GPS distance will differ.
Counts are limited to compatible stops and whole cargo units. Manual routes
must also fit the distance. If fewer than three deliveries fit, increase the
distance, change cargo/destination, or choose Single/Dual.

FULL TRAILER LOADS
Options > Full trailer loads lets new SplitHaul jobs use the attached
combination's own payload and volume capacity instead of country road-weight
limits. It is off by default and saved separately for each profile. Update
the app and game plugin together. Existing jobs and ordinary Cargo Market
offers are unchanged. Each delivery handover retains its original load policy.
The fuel-double diesel calculation is 60 units / 51 tonnes; in-game loading
and driving still need testing. Other combinations depend on their definitions.

DLC FILTERING (ATS AND ETS2)
City and depot choices automatically use packages mounted by the running game.
Start the chosen game and load your profile to refresh the list. Merely having
a DLC archive in Steam is not treated as ownership. Iceland and other bundled
map DLC cities appear only when their DLC is loaded. Unsupported mod-map cities
are not added automatically. Offline, only base-map depots are offered.
The app and both selected game DLLs must be updated together (protocol 5).
Multi-drop has automated checks; a complete in-game trip still needs verification.

UPDATES, ROLLBACK AND UNINSTALL
Close both games and the app before an update or uninstall.
Re-run Setup to update the app. Existing app versions are saved in app-backups;
previous game DLLs are saved in plugin-backups inside the installed app folder.
For a complete app rollback, use the previous matching installer with games closed.
On uninstall, the original game DLL is restored only if the current file still
matches the DLL installed by this installer. A DLL changed by another tool is
preserved. Saved user data and rollback backups remain on disk.
Installed trailer mods are also preserved on uninstall because purchased
trailers can depend on them. Previous mods are backed up outside the active
mod folder, in <game data folder>\mod-backups\DispatchCompanion.

UPDATES
In Options, press Check for updates. This includes published test releases.
If a newer version is available, the app offers to open its GitHub release page.
Download the installer, then close SplitHaul and both games normally
before running Setup. Existing app profiles, settings and history are retained.
Update checks are manual; nothing is downloaded or installed automatically.

RENAMED FROM DISPATCH COMPANION
Use the SplitHaul installer once to upgrade from the previous name. The old
update checker cannot follow the repository rename. Open SplitHaul once after
upgrading to register Shift+F9. Existing data under Grumpyman\DispatchCompanion
is reused in place; new users use Grumpyman\SplitHaul. Both app names must be
closed during installation. Previous executables are retained in app-backups.
